# PosterKit — sitio público

Páginas públicas de la app **PosterKit** (`com.vicktorsk.posterkit`),
servidas con GitHub Pages:

- `privacidad.html` — política de privacidad, requerida por Google Play
- `index.html` — portada

El código de la app vive en otro repositorio, privado. Aquí sólo hay
las páginas que tienen que ser públicas.
